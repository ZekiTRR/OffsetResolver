# Инструмент для анализа процессов и модулей памяти

C++ утилита для анализа памяти, отслеживания модулей и разрешения цепочек указателей в работающих процессах.

## Возможности

- **Управление процессами**: Поиск и подключение к процессам по имени
- **Реестр модулей**: Список загруженных модулей и получение их базовых адресов
- **Чтение памяти**: Типобезопасные операции с памятью (int32, float, double)
- **Цепочки указателей**: Разрешение многоуровневых указателей с проверкой
- **Экспорт структур**: Сохранение цепочек в формате, удобном для анализа и отладки
- **Хранилище конфигураций**: Сохранение/загрузка конфигов смещений в формате модуль+смещение (ASLR-совместимо)
- **Консольный интерфейс**: Интерактивное меню для всех операций

## Сборка

Требования: Windows 10/11, CMake 3.20+, компилятор C++17

```powershell
.\build.ps1
```

Или вручную:
```bash
mkdir build && cd build
cmake .. && cmake --build . --config Release
```

## Использование

1. Запустите приложение → главное меню
2. Подключитесь к процессу → введите имя процесса
3. Просмотрите загруженные модули → проверьте базовые адреса
4. Создайте/загрузите файл конфигурации смещений
5. Разрешите цепочки указателей и прочитайте значения

### Формат конфигурации

Файл `offsets.cfg`:
```ini
# Формат: имяМодуля+0xСмещение=Описание
engine.dll+0x649910=БазовыйУказатель
engine.dll+0x4DCC098=УказательДанных
utils.dll+0x58EFC4=ВспомогательныйУказатель
```

### Пример: Многоуровневый указатель

Разрешите цепочку указателей: `engine.dll+0x649910` → смещение 0x18 → смещение 0x70 → чтение как INT

```ini
engine.dll+0x649910=НачалоЦепочки
# Смещения: 0x18 → 0x70 → финальное чтение
```

### Типы значений
- **INT**: int32_t
- **FLOAT**: Одинарная точность
- **DOUBLE**: Двойная точность

## Важные детали

- **Адреса, относительные к модулям**: Сохраняются как `модуль+смещение` для совместимости с ASLR
- **Типобезопасность**: Явные типы данных предотвращают ошибки чтения
- **Валидация**: Все адреса и цепочки проверяются перед чтением
- **ASLR-совместимо**: Адреса сохраняются при перезапуске процесса

## Устранение неполадок

- **Процесс не найден**: Проверьте, что процесс запущен, проверьте правильность имени, может потребоваться правправа администратора
- **Модуль не загружен**: Обновите список модулей, проверьте имя модуля
- **Некорректный адрес**: Проверьте смещения указателей, адрес может быть в неотображаемой памяти
- **Ошибки чтения**: Проверьте права доступа, защиту памяти страницы, выгрузку модуля
